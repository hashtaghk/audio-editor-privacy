# Audio Editor — Privacy Policy

Public privacy policy for the **Audio Editor** Android app by Harix DevCo
(`harix.ringtone.maker.music.editor.free`).

Published with GitHub Pages: <https://hashtaghk.github.io/audio-editor-privacy/>

That URL is the one to enter in:

- Google Play Console → *Policy → App content → Privacy policy*
- The in-app **Settings → Privacy Policy** link

## Editing

The policy is a single self-contained `index.html` — no build step, no dependencies.
Edit it and push; GitHub Pages redeploys automatically.

When you change it, update **both** dates at the top of the page (`Effective` and
`Last updated`).
